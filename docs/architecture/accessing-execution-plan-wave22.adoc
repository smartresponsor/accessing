= Wave 22: Accessing User Administration Execution Plan

Accessing now publishes a metadata-only execution plan for controlled user-administration hardening.

The plan converts work/readiness metadata into execution-step descriptors that Administering can display.

The plan does not execute user mutations and does not expose sensitive user internals.

Forbidden payloads:

* password hashes
* TOTP secrets
* recovery codes
* reset tokens
* raw session payloads
* verification internals

Real user administration execution remains inside Accessing-owned services.
