= Accessing Admin Action Request Wave 10

Accessing now exposes `AccessingAccountAdministrationRequest` as a higher-level request DTO for Administering-driven account actions.

The DTO carries only safe metadata:

* controlled action key;
* account reference;
* requester subject;
* safe reason;
* safe context.

The request converts to `AccessingAccountAdministrationAction` at the Accessing bridge boundary. Accessing still owns execution and may reject unsupported actions. Administering must not raw-edit password hashes, TOTP secrets, recovery codes, verification internals, or raw session payloads.
