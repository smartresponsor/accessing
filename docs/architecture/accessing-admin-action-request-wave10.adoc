= Accessing Admin Action Request Wave 10

Accessing now exposes `AccessingUserAdministrationRequest` as a higher-level request DTO for Administering-driven user actions.

The DTO carries only safe metadata:

* controlled action key;
* user reference;
* requester subject;
* safe reason;
* safe context.

The request converts to `AccessingUserAdministrationAction` at the Accessing bridge boundary. Accessing still owns execution and may reject unsupported actions. Administering must not raw-edit password hashes, TOTP secrets, recovery codes, verification internals, or raw session payloads.
