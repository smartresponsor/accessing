= Accessing Wave 8: Controlled Admin Action Catalog

Accessing now exposes safe metadata for controlled user administration actions.

== Purpose

Administering may display which user actions exist, but Accessing remains the owner of the actual user/session/security internals.

== Allowed action classes

* lock user
* unlock user
* terminate session
* request 2FA reset
* view security events

== Forbidden raw edits

Administering must not raw-edit password hashes, TOTP secrets, recovery codes, reset tokens, verification internals, or raw session payloads.
