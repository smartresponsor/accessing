= Accessing Admin Audit Projections - Wave 14

Accessing now exposes a safe projection provider for controlled user administration audit records.

The projection is intended for Administering UI and diagnostics. It carries only metadata:

* action key
* user reference
* requesting subject
* result status
* safe message
* creation timestamp
* safe context

Forbidden data:

* password hashes
* TOTP secrets
* recovery codes
* reset tokens
* raw session payloads
* verification internals

Accessing remains the owner of login, logout, sessions, credentials, two-factor internals, and user security state.
