= Accessing Doctrine Admin Projections Wave 7

Accessing now provides a Doctrine-backed safe user projection provider for Administering.

== Boundary

Accessing still owns:

* user identity
* authentication
* login/logout
* session state
* password hash
* 2FA internals
* recovery codes
* reset-password internals
* verification internals

Administering receives only safe projection metadata:

* `accessing:user:{id}` subject id
* user identifier
* active/locked state
* email verification state
* bootstrap roles
* display name

== ACL handoff

The projection subject id is the stable identity key that Rolling can use for subject-role assignment and policy decisions. Accessing does not own dynamic ACL.
